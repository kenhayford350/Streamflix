# Streamflix
 A Power BI dashboard project analyzing user ratings and movie data from StreamFlix — uncovering key trends, top genres, and performance insights to support business development strategies.
🎥 StreamFlix Business Development Dashboard
This project is a comprehensive Power BI dashboard built to analyze and visualize user engagement and movie performance for StreamFlix, a fictional streaming service. It leverages viewer behavior, genre trends, and regional engagement to inform business strategy and content development decisions.


📁 Project Files
File Name	Description
BUSINESS DEVELOPMENT DASHBOARD OF STREAMFLIX.pbix	Interactive Power BI dashboard
ratings.csv	Raw user ratings (userId, movieId, rating, timestamp)
movies.xlsx	Metadata of movies (title, genre, year, views, language, country)
image.png	Sample snapshot of movie data used
🎯 Project Objective
To uncover insights that support content curation, audience segmentation, and regional strategy for the StreamFlix platform. The dashboard focuses on:

Viewer preferences by genre, language, and region

Most-watched movies based on total views

Highly rated and trending titles

Viewer engagement trends across countries

🔍 Data Summary
The dataset includes:

21 Movies from the year 1995

Attributes like Genre, Language, Country of Viewing, and Total Views

Example entries:

Toy Story (Germany, Italy): 69,118 views

Waiting to Exhale (Spanish, India): 84,783 views

Nixon (Spanish, UK): 98,502 views

Sense and Sensibility (Italian, France): 91,178 views

Genres include: Comedy, Drama, Action, Adventure, Romance, Thriller, Animation, and Fantasy.

📊 Key Dashboard Insights
✔️ Top 5 Most Viewed Movies
✔️ Most Popular Genres Globally
✔️ Countries with Highest Viewer Counts
✔️ Language Preferences for Different Markets
✔️ Viewership Trends by Genre and Country
